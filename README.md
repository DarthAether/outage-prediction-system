# AI-Driven Disaster-Aware Power Outage Prediction System

This project implements an end-to-end machine learning system to predict
power outages 24 hours in advance using weather and historical outage data.
The system includes a simulated IoT edge-to-cloud pipeline and is designed
to be reproducible, explainable, and industry-relevant.

Core focus:
- Weather-driven outage prediction
- Disaster-aware risk modeling
- Edge-to-cloud system simulation
- Research-grade evaluation and documentation
