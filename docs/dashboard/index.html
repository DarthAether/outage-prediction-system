Research Contributions
Three novel contributions to the power systems reliability literature.
Contribution 01
Compound Event Features
Co-occurrence matrices, pairwise severity products, and sequential escalation scores across 6 weather categories. The composite severity index ranks 18th among 138 features.
Contribution 02
Calibrated Uncertainty
Ensemble disagreement between XGBoost and LightGBM with post-hoc isotonic calibration. ECE reduced from 0.267 to 0.004 — a 98.4% reduction.
Contribution 03
Simulated Transfer Experiment
YAML config files encode regional thresholds and hazard profiles. Transfer was explored across state-context datasets produced by the same synthetic target generator; this is not measured utility validation.
