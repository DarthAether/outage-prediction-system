// Key Features

Capabilities

🌩️

Compound Event Modeling

Captures non-linear interactions between concurrent weather hazards -- wind, rain, temperature, and humidity combined into 138 engineered features.

📍

H3 Spatial Indexing

Uber's H3 hexagonal grid system for consistent geospatial aggregation, enabling cross-state generalization without boundary artifacts.

🎯

Calibrated Uncertainty

Platt-scaled probability calibration achieves 0.004 ECE, ensuring predicted risk scores match observed outage frequencies.

🌎

Cross-State Generalization

State-agnostic architecture trained across 3 diverse U.S. states -- transfers to unseen regions without retraining.

⚠️

Real-Time Alerts

WebSocket-driven live prediction updates with configurable alert thresholds and push notifications for grid operators.

📊

MLflow Experiment Tracking

Full experiment lifecycle management with model versioning, metric logging, and reproducible training runs.

🤖

3-Model Ensemble

XGBoost, LightGBM, and LSTM combined via stacking for robust predictions that outperform any single model.

🔄

CI/CD Pipeline

Automated testing, linting, and Docker-based deployment with GitHub Actions for continuous integration.

// Quick Start

Get Running

terminal 
# Clone the repository
git clone https://github.com/DarthAether/outage-prediction-system.git
cd outage-prediction-system

# Start all services
docker-compose up -d

# Access the dashboard
# Frontend:  http://localhost:3000
# API:       http://localhost:8000/docs
# MLflow:    http://localhost:5000

# Run tests
docker-compose exec api pytest -v
