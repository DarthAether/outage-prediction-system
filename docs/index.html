Key Highlights
  • 138 engineered features spanning weather, temporal, infrastructure, and compound event categories
  • H3 hexagonal spatial indexing at resolution 7 for uniform spatial analysis
  • Compound-event features covering co-occurrence and sequential storm patterns
  • Isotonic calibration reduces ECE from 0.267 to 0.004 (98.5% improvement)
  • 12,000-sample research benchmark using physics-informed synthetic outage targets
  • Measured utility-outage validation remains future work; this dashboard is a research demonstration
